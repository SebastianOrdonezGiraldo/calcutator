# Calcutator

A simple Python calculator project following TDD principles.

## Project Structure
- `calculator/calculator.py`: Contains the `Calculator` class.
- `calculator/test_calculator.py`: Unit tests for the calculator.
- `evidencias/`: Screenshots of the testing phases.

## How to Run Tests
You can run the tests locally using:
```bash
python calculator/test_calculator.py
```

## Continuous Integration
This project uses GitHub Actions for CI. The workflow is defined in `.github/workflows/ci.yml` and runs on every push or pull request to the `main` branch.
